quad-phase-amphibio. # 🔋 quad-phase-amphibio: 4-Person Amphibious Energy-Velomobile An ultra-reliable, modular 4-operator hybrid energy velomobile designed for long-distance, off-grid expeditions. ## 🛠 Project Highlights * **System:** 4-Phase Interconnected Crankshaft System. * **Power:** 48V LiFePO4 Battery & DC-DC Matrix. * **Build:** 6061-T6 Aluminum Amphibious Frame (IP67). * **Core Feature:** 4-person, 0% torque ripple, 400km range. ## 📊 Performance Comparison: Solo vs. 4-Phase System Unlike solo cycling, the 4-phase system provides continuous torque, eliminating dead spots and reducing muscle fatigue. | Criterion | Solo Bike | 4-Phase Velomobile | | :--- | :--- | :--- | | **Torque** | Critical (0-100% ripple) | 0% (Smooth, continuous) | | **Muscle Fatigue** | High | Low (Aerobic zone) | | **Uphill Speed** | ~1.5–2 km/h (Pushing) | ~3.77 km/h (Pedaling) |
