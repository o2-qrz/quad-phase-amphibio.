# 🔋 quad-phase-amphibio: 4-Person Amphibious Energy-Velomobile An ultra-reliable, modular 4-operator hybrid energy velomobile built for extreme long-distance expeditions, off-grid power harvesting, and tactical tourism. --- ### 📸 TECHNICAL DIAGRAM & APPEARANCE ![General View](www5.png) --- ## 🛠 Project Highlights * **System:** 4-Phase Interconnected Crankshaft System (90° Phase Shift Alignment). * **Power:** 48V LiFePO4 Battery & Direct Current Distribution (DC-DC Matrix). * **Build:** 6061-T6 Aluminum Amphibious Frame with IP67 Sealed Avionics. * **Core Feature:** 4-person capacity, 0% torque ripple, continuous motion. ## 📊 Performance Comparison: Solo vs. 4-Phase System Unlike solo cycling, the 4-phase system provides continuous torque, eliminating dead spots and reducing muscle fatigue. | Criterion | Solo Bike | 4-Phase Velomobile | | :--- | :--- | :--- | | **Torque Ripple** | Critical (0-100% ripple) | 0% (Smooth, continuous) | | **Muscle Fatigue** | High | Low (Aerobic zone recovery) | | **Uphill Speed** | ~1.5–2 km/h (Dismount/Pushing) | ~3.77 km/h (Continuous Pedaling) | ## 📐 Key Technical Features 1. **"Carousel" Rotation Scheme (3 Pedaling, 1 Resting On-the-Fly):** Delivers a stable cruising speed of 28–32 km/h on flat terrain and enables a continuous daily range of up to 400 km. 2. **Amphibious Protocol (River Crossing):** Modular 200-liter inflatable PVC pontoons attach directly beneath the aluminum frame. 3. **Stationary Generation (Camp Mode):** The rear drive axle decouples from the terrain via an integrated kickstand-jack, harvesting ~180W of continuous DC power to recharge camp equipment. 4. **Direct Current Distribution (DC-DC Matrix):** Complete elimination of heavy 220V AC inverters. Output rails include: 5V (USB-C PD 100W), 12V, 24V (thermal mats), 36V, and native 48V (direct-arc welding / Starlink nodes). --- ## 🔗 Related Projects * [Powered-Mobile-3](https://github.com) * [Stealth-Cato-Bahes-1](https://github.com)
